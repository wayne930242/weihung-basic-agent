# Rotating a long-lived session

A long-lived main (a standing session, or a coordinator that runs for days) rotates its session only on a concrete problem: `pi-session-doctor` measures repeated main-thread stalls the session's own state causes, or compaction has visibly lost context the work needs. A milestone, a long history, or a doctor nudge alone is no reason, because a new session starts without the prompt cache. To rotate, write `scratch/handoff-<name>.md` with the goal, the open todos only, the monitors and loops to recreate, the replies you owe and to whom, the branches and worktrees in flight, the loop's book id (the `book:` line of `anchorloop_stage read`), and the user's last instructions verbatim, then open your successor yourself with `boss_handover {handoff: "scratch/handoff-<name>.md", reason: <the concrete problem>}`: it opens a new tab in your workspace with a pi under your name and kind whose first prompt is the handoff. Only where `boss_handover` is missing (pi-straw-boss before 0.82.0), open it yourself with `herdr tab create` and start pi there on the handoff; never ask the user to run `/new`. The new session reads the handoff, passes the book id as `resume` on its first `anchorloop_stage kind`, recreates the monitors and loops, keeps the kind it was opened with (it runs `boss_duty` only when the handoff names a different kind), and drops completed todos. Then it tells the old session by intercom (the handoff names its id) that it took over. The old main then gives up its role, because towers route standing work by kind and name, and two standing mains of one name both get it: it runs `boss_duty coordinator` (when it was standing or integrator), renames itself with `boss_rename` to `old <name> (handed over to <new id>)`, stops its monitors and loops, clears its board, and waits for its workspace's tower to close it: `boss_handover` tells the tower, which closes the old main once its successor is live, whoever opened it. With no tower in the workspace, the user closes it. Never run `/new`, kill a process, or stop running work to rotate.
